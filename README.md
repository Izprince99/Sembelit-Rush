# 🏍️ Selit Rush

Game motor menyelit di jalan raya Malaysia, dimainkan terus dalam browser.
Tak perlu install apa-apa, boleh main di phone atau laptop.

▶️ **Main sekarang:** https://izprince99.github.io/Sembelit-Rush/

## Cara main
| | Laptop | Phone |
|---|---|---|
| Belok | ← → atau A / D | Tekan kiri / kanan skrin |
| Pecut | ↑ atau W | Butang ⚡ |
| Brek | ↓ atau S | Butang 🛑 |
| Bunyi | M | Butang 🔊 |

## Peraturan
- ❤️ **5 nyawa**: gesel tepi kenderaan hilang 1 nyawa
- 🕳️ **Lubang jalan**: motor hilang kawalan sekejap
- 💥 **Game over**: langgar belakang kenderaan atau langgar haiwan
- 🚑 **Ambulans**: bagi laluan, kalau tak kena tolak!

## Ciri-ciri
- Makin lama main, makin laju
- Haiwan melintas tiba-tiba: lembu, gajah, buaya, monyet, babi
- Power-up 🛡️ Perisai & 🔫 Tembak
- Cuaca berubah: cerah → hujan → ribut petir ⛈️
- Muzik rock, bunyi enjin 4 silinder & rekod terbaik disimpan

Dibina dalam satu fail `index.html` sahaja: HTML, CSS & JavaScript, tanpa gambar atau fail luar.
